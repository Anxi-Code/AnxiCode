# AnxiCode

> **Battling Code Anxiety Together**

AnxiCode is a gamified coding practice platform designed to help
learners improve programming skills, build confidence, and overcome code
anxiety through structured learning, debugging challenges, quizzes, and
real-time coding battles.

![AnxiCode Preview](anxicode_linkedin_post.png)

## Features

-   Gamified coding learning progression
-   Multi-language practice: **C++, Python, Java, and JavaScript**
-   Topic-based ranks and progress tracking
-   Interactive quizzes and coding challenges
-   Error Tracking Arena for debugging practice
-   Syntax Forge for syntax and code verification
-   Real-time coding battles
-   AI-powered feedback and adaptive learning

## Tech Stack

-   **Frontend:** Flutter
-   **Backend:** Python, FastAPI
-   **Database & Storage:** Supabase
-   **Authentication & Matchmaking:** Firebase
-   **Execution & Deployment:** Docker, Kubernetes, AWS
-   **AI/ML:** AI-assisted code analysis and personalized feedback
